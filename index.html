FAQ

Good to know.

What is FilmRoll Manager?

FilmRoll Manager is a free desktop app for macOS and Windows (beta) that prepares your film scans from the lab for your photo library. It can reverse the frame order of a roll, embed date, camera, lens and film as metadata, rename a whole roll with a template and create printable contact sheets. Everything happens on your computer, your scans are never uploaded.

Does FilmRoll Manager change my images?

Only metadata is written. The picture data stays untouched. Still, it is a good habit to try FilmRoll Manager on a copy of a scan folder first.

Which file types are supported?

JPG, PNG and TIFF. Star ratings currently work for JPEG files only.

Are my scans uploaded anywhere?

No. Everything happens on your computer. There are no uploads, no account and no analytics.

Is it really free?

Yes. I built it for my own rolls and share it for free.

Download for macOS

Before you download

Heads up: macOS will most likely block the app the first time you open it. That is expected. The steps below fix it.

FilmRoll Manager is not signed with an Apple developer account, so macOS asks for confirmation the first time you open it.

  1. Open the .dmg and drag FilmRoll Manager into Applications.
  2. Right-click the app and choose “Open”.

If macOS still refuses to open it, run this command once in Terminal:

xattr -dr com.apple.quarantine "/Applications/FilmRoll Manager.app"

Download for Windows (beta)

Before you download

Heads up: Windows will most likely block the installer the first time you run it. That is expected.

FilmRoll Manager is not signed with a paid Windows certificate, so Windows SmartScreen warns about it.

  1. Run the downloaded .exe.
  2. At “Windows protected your PC”, click More info.
  3. Then click Run anyway.
