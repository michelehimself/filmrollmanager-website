FAQ

Good to know.

Does it change my images?

Only metadata is written. The picture data stays untouched. Still, it is a good habit to try it on a copy of a scan folder first.

Which file types are supported?

JPG, PNG and TIFF. Star ratings currently work for JPEG files only.

Are my scans uploaded anywhere?

No. Everything happens on your computer. There are no uploads, no account and no analytics.

Is it really free?

Yes. I built it for my own rolls and share it for free.

When will Windows and Linux be available?

The app is built to run on both, but there is no date yet. The download buttons go live as soon as the builds are ready.
